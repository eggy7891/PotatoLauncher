# Latest PotatoLauncher

This directory is the stable entry point for the newest official PotatoLauncher release.

- [Download the latest Windows x64 portable build](https://github.com/eggy7891/PotatoLauncher/releases/latest/download/PotatoLauncher-win-x64-portable.zip)
- [Open the latest GitHub Release](https://github.com/eggy7891/PotatoLauncher/releases/latest)
- `version.json` records the release represented by this directory.
- `PotatoLauncher.url` is a Windows Internet Shortcut to the stable download URL.
- `Get-Latest.ps1` downloads the current package with PowerShell.

The release process uploads both a versioned asset and the stable
`PotatoLauncher-win-x64-portable.zip` alias. Therefore the URLs above always
resolve to the newest non-prerelease build.
